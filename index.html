How to Use

Nine steps to
clipboard mastery

01
Install & Pin
After installing from Chrome or Edge store, click the puzzle-piece icon, find QuickClip Pro and pin it. Click the pinned icon to open the sidebar - it stays open while you browse.
Toolbar → Pin → Click to Open
02
Save a Snippet
Type or paste any text, URL, or image. Select a status tag from the dropdown, then hit Save. Use Paste to clipboard-read and save in one tap. Links auto-detect and become clickable.
Type → Tag → Save OR Paste & Save
03
Manage Snippets
Click to copy instantly. Click to delete. Double-click any snippet text to edit inline - saves automatically when you click outside. No extra steps.
Double-click to Edit · Click outside to Save
04
Execution Counter
The Execution Count in the header tracks repeated tasks. Hit + to increment, − to decrement, reset icon to return to zero. Create multiple mini-counters in Settings.
+ / − /Reset · Mini-Counters in Settings
05
Search & Filter
Use the search bar to find by content, the calendar picker to filter by date, or the tag dropdown to narrow by status. All three filters work simultaneously in real time.
Search · Date · Tag - all real-time
06
Settings
Click the gear icon in the header. Add/rename/hide mini-counters, create custom tags, toggle light/dark/system theme, show or hide individual UI elements.
→ Counters · Tags · Theme · Display
07
Add Images
Click the camera icon in the input area to upload an image. Stored locally alongside text - great for UI mockups, screenshots, or any visual reference.
Camera → Upload → Save
08
Export & Import
In Settings → Data Management, click Export Data to download a JSON backup. Click Import Data to restore. Always export before importing - import overwrites current data.
→ Data → Export / Import JSON
09
Custom Tags
Create up to 8 custom tags with different colors. In Settings → Tags, rename any tag and choose from multiple color options. Perfect for project, priority, or workflow categorisation.
→ Tags → Rename & Color (8 available)

Legal

Privacy & License

Complete, unabridged. No legalese for its own sake.

Privacy Policy
Zero Data Collection. QuickClip Pro does not collect any data whatsoever. No servers, no accounts, no analytics. Nothing you type, save, paste, or do inside the extension is ever transmitted outside your device.
Local Storage Only. All snippets, counters, tags, and settings are stored in chrome.storage.local. A browser-managed, device-local API - the developer has no access under any circumstances.
No Tracking or Monitoring. No usage statistics, no event logging, no crash reporting, no heatmaps, no third-party analytics SDKs of any description. Not even page-view counts.
Permissions Explained. Only what it needs: storage, clipboardRead & clipboardWrite, and sidePanel. No tabs, no host permissions, no browsing history access.
Open Source Verification. Entire codebase is on GitHub, no obfuscation. Anyone can verify no data leaves the device.
Data Persistence & Loss. Data persists between sessions while the browser profile is intact. Clearing browser data or uninstalling will erase it permanently. Export regularly via Settings → Data Management → Export.
