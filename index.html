How to Use

Nine steps to
clipboard mastery

01
Install & Pin
After installing from the Chrome or Edge store, click the puzzle-piece icon, find QuickClip Pro and pin it. Click the pinned icon to open the sidebar - it stays open while you browse without interrupting your tabs.
Toolbar → Pin → Click to Open
02
Save a Snippet
Type or paste any text, URL, or image into the input area. Select a status tag from the dropdown, then hit Save. Use Paste to clipboard-read and save in one tap. Links auto-detect and become clickable.
Type → Tag → Save OR Paste & Save
03
Manage Snippets
Click 📋 to copy a snippet instantly. Click 🗑️ to delete it. To edit, double-click the snippet text, make changes, then click outside - saves automatically with no extra steps.
Double-click to Edit · Click outside to Save
04
Execution Counter
The Execution Count in the header tracks repeated tasks. Hit + to increment, − to decrement, the reset icon to return to zero. Create multiple independent mini-counters in Settings for different tasks.
+ / − / ↺ Reset · Mini-Counters in Settings
05
Search & Filter
Use the search bar to find by content, the calendar picker to filter by date, or the tag dropdown to narrow by status. All three filters work simultaneously in real time - instant results.
Search · Date · Tag - all real-time
06
Settings
Click the ⚙️ gear icon in the header. Add/rename/hide mini-counters, create custom tags, toggle light/dark/system theme, show or hide individual UI elements, and configure double-click edit behaviour.
⚙️ → Counters · Tags · Theme · Display
07
Add Images
Click the 📷 camera icon in the input area to upload an image. It is stored locally alongside your text content - great for UI mockups, screenshots, or any visual reference you need close at hand.
📷 Camera → Upload → Save
08
Export & Import
In Settings → Data Management, click Export Data to download a JSON backup of all snippets, counters and settings. Click Import Data to restore. Always export before importing - import overwrites current data.
⚙️ → Data → Export / Import JSON
09
Custom Tags
Create up to 8 custom tags with different colors for organization. In Settings → Tags, rename any tag, choose from multiple color options, and assign them to snippets. Perfect for categorizing by project, priority, or workflow stage.
⚙️ → Tags → Rename & Color (8 available)

Privacy & License

Complete, unabridged. No legalese for its own sake.

Privacy Policy
Zero Data Collection. QuickClip Pro does not collect any data whatsoever. There are no servers, no accounts, no analytics pipelines, and no telemetry of any description. Nothing you type, save, paste, or do inside the extension is ever transmitted anywhere outside of your own device.
Local Storage Only. All snippets, counters, tags, and settings are stored exclusively in your browser's chrome.storage.local API. This is a browser-managed, device-local storage - the developer has no access to it under any circumstances. Your data never leaves your machine.
No Tracking or Monitoring. There are no usage statistics, no event logging, no crash reporting, no heatmaps, no user session recordings, and no third-party analytics SDKs included in any form. Not even page-view counts.
Permissions Explained. The extension requests only what it needs: storage to save data locally; clipboardRead & clipboardWrite for the Paste and Copy operations; sidePanel to render the sidebar UI. No tabs, no host permissions, no browsing history access.
Open Source Verification. The extension is fully open source. The entire codebase is available on GitHub for independent inspection. There is no obfuscation. Anyone can verify that no data leaves the device by reading the source.
Data Persistence & Loss. Data persists between browser sessions as long as your browser profile is intact. Clearing browser data, uninstalling the extension, or resetting your Chrome/Edge profile will permanently erase locally stored data. Export regularly via Settings → Data Management → Export to prevent data loss.
Children's Privacy. The extension does not knowingly collect any personal information from children under 13 or under any applicable age of digital consent. The extension collects no personal information from any user.
Policy Updates. This privacy policy may be updated when the extension updates. Changes are communicated via the GitHub repository changelog. Continued use of the extension following notification of changes constitutes acceptance of the revised policy.
